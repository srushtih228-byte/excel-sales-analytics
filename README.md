Sales Operations Analytics (Excel Project)
Tools Used: Excel (Advanced Formulas, Pivot Tables, Data Cleaning)

Project Overview
Analyzed 2,000+ rows of messy retail data across 6 Indian cities to answer business questions for a leadership review.

Key Skills Demonstrated
Data Cleaning: Handled broken foreign keys, inconsistent casing (whitespace), and duplicate Order IDs using TRIM, PROPER, and ISNA(MATCH()).

Lookups: Used INDEX/MATCH and nested VLOOKUPs for chained data retrieval and self-joins.

Aggregation: Built helper columns to calculate multi-sheet metrics using SUMIFS, AVERAGEIFS, and MAXIFS.

Analysis: Built Pivot Tables for 2D analysis and used calculated fields for profit margins.

Advanced: Used TEXTJOIN, LARGE, and array formulas for top-N analysis.
